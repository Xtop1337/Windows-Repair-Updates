## WURepair — ремонт Центра обновления Windows 10

**Скачайте `WURepair-<версия>.zip`**, распакуйте целиком и запустите `WURepair.exe` (или `START.bat`, если антивирус блокирует exe).

1. **Найти проблемы** — проверка, ничего не меняет.
2. **Исправить всё автоматически** — с точкой восстановления и резервными копиями.
3. **Найти и установить обновления.**

Дополнительно: установка Claude Desktop (нужна Windows 10 2004+ / сборка 19041+), восстановление Microsoft Store и Защитника, DISM + SFC, обновление Windows поверх до 22H2 с сохранением файлов и программ, отчёт и откат.

Сборка проверена в GitHub Actions на Windows: модульные тесты, интеграционный тест «сломать → найти → починить» и смоук-тест окна.
