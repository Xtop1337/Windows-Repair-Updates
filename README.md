# WURepair — ремонт Центра обновления Windows 10

Программа с окном и кнопками, которая **сама находит, почему не работает Центр обновления Windows 10, и чинит это**. Ещё она возвращает Microsoft Store и Защитник и помогает установить Claude Desktop.

Сделана для случаев, когда Windows «почистили» программами вроде Win10Debloater, DWS (Destroy Windows Spying), O&O ShutUp10, Windows Update Blocker, когда стоит урезанная «сборка» или обновления просто сломались.

> Программа **не изменяет и не обходит активацию Windows**.

---

## Как скачать и запустить

1. Откройте раздел **[Releases](../../releases/latest)** этого репозитория.
2. Скачайте **`WURepair-<версия>.zip`**, распакуйте его **целиком** в любую папку (например, на Рабочий стол).
3. Запустите **`WURepair.exe`** и разрешите запуск от имени администратора (нажмите «Да»).
   - Если Windows покажет «Windows защитила ваш компьютер» → **«Подробнее» → «Выполнить в любом случае»** (у программы нет платной цифровой подписи).
   - Если антивирус (Касперский, ESET, Dr.Web) удалит или заблокирует `WURepair.exe`, запустите **`START.bat`** из того же архива. Это та же программа, только в виде скрипта PowerShell.

Нужна Windows 10 (подойдёт и Windows 11), учётная запись с правами администратора и интернет.

## Порядок работы

| Шаг | Кнопка | Что происходит |
|---|---|---|
| 1 | **Найти проблемы** | Полная проверка (2–6 минут). Программа ничего не меняет, а показывает список проблем: красным отмечены ошибки, жёлтым — предупреждения. Двойной щелчок по строке открывает подробности. |
| 2 | **Исправить всё автоматически** | Создаёт точку восстановления и резервные копии, затем исправляет всё найденное. В конце проверяет систему ещё раз. |
| 3 | **Найти и установить обновления** | Ищет, скачивает и ставит обновления прямо из программы, даже если окно «Центр обновления» в Параметрах не открывается. |

Если не помогло, нажмите **«Обновить Windows поверх (до 22H2)»**. Это самый надёжный способ (подробнее ниже).

## Что проверяется и исправляется

- **Службы**: Центр обновления, BITS, криптография, оркестратор обновлений, установщик модулей, службы Магазина и установки приложений (AppX), брандмауэр, служба времени. Программа находит отключённые службы, подменённые пути и учётные записи, а также запреты в правах служб, которые ставят «блокировщики».
- **Политики**: запрет Центра обновления, чужой сервер обновлений (WSUS), «закреплённая» версия Windows, пауза обновлений на годы, скрытые страницы Параметров, запрет Магазина, запрет установки приложений MSIX, отключение Защитника. Если запреты записаны в локальную групповую политику (gpedit), программа убирает из неё только эти записи, а остальные политики не трогает.
- **Сетевые блокировки**:
  - Файл `hosts`: из него убираются блокировки серверов Microsoft, а чисто «шпионские» адреса телеметрии остаются заблокированными.
  - «Мёртвые» постоянные маршруты, которые оставляет DWS.
  - Правила брандмауэра, блокирующие обновления.
  - Сломанный прокси.
- **Блокировка запуска** компонентов обновления через Image File Execution Options.
- **Задания планировщика** автоматического обновления.
- **Неверные дата и время**: из-за них не проходят защищённые соединения.
- **Доступность серверов** Microsoft и claude.ai.
- **Журналы ошибок** Центра обновления и установки приложений. Коды ошибок программа расшифровывает на русском: в ней есть база из ≈100 кодов (0x80070422, 0x8024402C, 0x800F081F, 0x80073CFF…).
- **Пробный поиск обновлений** — «живая» проверка, работает ли Центр обновления на самом деле.
- **Хранилище компонентов и системные файлы**: восстанавливаются через DISM и SFC, при необходимости по ISO-образу.
- **Признаки урезанной «сборки»** Windows.
- **Известная проблема KB5034441** (ошибка 0x80070643): это обновление программа скрывает, на работу Windows оно не влияет.

## Claude Desktop

Кнопка **«Установить Claude Desktop»**:

1. Проверяет требования из [официальной документации](https://support.claude.com/en/articles/12622703-deploy-claude-desktop-for-windows):
   - **Windows 10 версии 2004 (сборка 19041) или новее**;
   - 64-разрядная система;
   - Windows не в режиме S.
2. Исправляет препятствия: разрешает установку доверенных приложений MSIX (без этого появляется ошибка 0x80073CFF) и включает нужные службы.
3. Скачивает **официальный пакет** с `claude.ai`, проверяет подпись Anthropic и устанавливает его.
4. По желанию включает компонент «Платформа виртуальной машины» — он нужен для режима Cowork.

Если сборка Windows старше 19041, сначала обновите Windows кнопкой «Обновить Windows поверх».

## Microsoft Store и Защитник

- **Вернуть Microsoft Store.** Программа пробует по очереди:
  1. зарегистрировать файлы, которые остались на диске;
  2. встроенную переустановку (`wsreset -i`);
  3. официальный «Установщик приложений» (winget) с [GitHub Microsoft](https://github.com/microsoft/winget-cli).
- **Вернуть Защитник.** Программа снимает запреты, восстанавливает службы и приложение «Безопасность Windows».
  - Если работает Касперский, ESET или Dr.Web, Защитник останется выключенным. Так и должно быть.
  - Если файлы Защитника удалены, вернуть его можно только обновлением поверх.

## Обновление Windows поверх (до 22H2)

Если система сильно «почищена» или это урезанная сборка, надёжнее всего переустановить Windows поверх с официального образа Microsoft. Что при этом происходит:

- **личные файлы и программы сохраняются**;
- удалённые компоненты (Магазин, Защитник, службы) **возвращаются**;
- Windows обновляется до последней версии 22H2.

Программа предлагает три варианта:

1. **«Помощник по обновлению» Microsoft.** Самый простой вариант: программа скачивает его и проверяет подпись Microsoft.
2. **Свой ISO-образ.** Программа проверяет, что выпуск, язык и разрядность образа совпадают с системой, и запускает установку поверх.
3. **Страница загрузки Windows 10** на сайте Microsoft (Media Creation Tool).

Что нужно знать заранее:

- Нужно около 20 ГБ свободного места.
- Обновление займёт 30–90 минут и несколько перезагрузок.
- Сторонний антивирус на время обновления лучше отключить.

## Безопасность

- Перед ремонтом программа создаёт **точку восстановления Windows**.
- Всё, что программа меняет (ключи реестра, `hosts`, правила брандмауэра, права служб, групповые политики), сначала копируется в `C:\WURepair\Backup\<дата>`.
- Кнопка **«Откатить изменения»** возвращает всё из копии.
- Журналы лежат в `C:\WURepair\Logs`.
- Кнопка **«Сохранить отчёт»** кладёт на Рабочий стол текстовый отчёт со всеми проблемами и журналом. Его можно отправить тому, кто помогает с ремонтом.
- Скачивания идут только с официальных адресов (microsoft.com, github.com/microsoft, claude.ai), подписи файлов проверяются.

## Важно про Windows 10

Поддержка Windows 10 закончилась **14 октября 2025 года**. Исправления безопасности теперь приходят только по программе расширенной поддержки (ESU). Если компьютер подходит для Windows 11, со временем лучше перейти на неё.

## Для разработчиков

```
src/WURepair.ps1        окно (WinForms); движок работает в фоновом runspace
src/engine/01-core.ps1   журнал, запуск процессов, реестр, резервные копии
src/engine/02-errors.ps1 база кодов ошибок → описание + исправления
src/engine/03-data.ps1   таблицы: службы, политики, домены, IFEO, задания
src/engine/04-diagnostics.ps1  проверки Test-*
src/engine/05-repair.ps1       исправления Repair-*, автоматический ремонт
src/engine/06-apps.ps1         установка обновлений, Store, Защитник, Claude
src/engine/07-upgrade.ps1      обновление поверх, отчёт, откат, диспетчер задач
build/Build.ps1         склейка в один .ps1 + сборка .exe (PS2EXE) + zip
tests/                  Pester-тесты, интеграционный тест для CI, смоук-тест окна
```

- Запуск из исходников: `START.bat` или `powershell -ExecutionPolicy Bypass -STA -File src\WURepair.ps1`.
- Тесты: `Invoke-Pester tests/WURepair.Tests.ps1`.
- Сборка: `./build/Build.ps1 -Version 1.0.0`.
- Все `.ps1` хранятся в UTF-8 **с BOM**: иначе Windows PowerShell 5.1 испортит кириллицу.

GitHub Actions (`.github/workflows/release.yml`) на каждый push делает следующее на настоящей Windows:

1. Гоняет тесты.
2. Запускает интеграционный тест: «ломает» виртуальную машину так же, как это делают чистильщики, и проверяет, что программа всё находит и чинит.
3. Делает скриншот окна.
4. Собирает `.exe` и публикует релиз.
